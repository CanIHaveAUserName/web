on Oracle Always Free.

1. How it works

The Oracle VM is the only public Minecraft endpoint. HAProxy accepts a player's TCP connection and forwards it through the encrypted Tailscale network to the Minecraft PC's private Tailscale address.

Players need nothing extra: they enter your domain or Oracle public IP in the normal Minecraft Java multiplayer screen. Tailscale is only between the Oracle VM and the computer hosting Minecraft.
Player IP and bans: A raw TCP relay hides players' real IP addresses from the Minecraft Java console. The server sees the relay's Tailscale address instead, so vanilla IP bans become far less useful: banning it can block every player using the relay. Moderate with Minecraft accounts, permissions, logs, and server-side tools rather than relying on IP bans alone.

2. Oracle Always Free relay pros and cons

This option is best when avoiding a monthly relay bill is more important than guaranteed capacity and uptime.

Pros

  • Always Free eligibility can provide a public relay without a recurring VM charge.
  • Hides your home IP and removes the need to expose TCP 25565 on your home router.
  • Players join normally with a public IP or domain; they do not need Tailscale, mods, or a custom launcher.
  • HAProxy and Tailscale use very little compute, so the micro VM is suitable for a small relay.
  • The relay keeps the public-facing traffic separate from your home network.

Cons

  • Always Free capacity is not guaranteed, so the required VM shape may be unavailable when you try to create it.
  • Oracle can reclaim eligible idle free instances under its policy, so this is not the best choice when uninterrupted availability is essential.
  • The micro VM has modest CPU, memory, and bandwidth limits, leaving less room for unusually busy servers or other services.
  • Players' real IPs are hidden from the Minecraft server, which makes vanilla IP bans ineffective for individual players.
  • It still needs maintenance: Oracle firewall rules, Ubuntu updates, Tailscale, HAProxy, and backups of the configuration.

3. Create the Oracle Always Free VM

Sign in to the Oracle Cloud Console. Always Free compute must be created in the tenancy's home region, and free capacity can be temporarily unavailable.

SettingUse this value
ImageUbuntu 24.04 (Always Free eligible, if offered)
ShapeVM.Standard.E2.1.Micro (AMD)
CPU1/8 OCPU — not a full CPU core
Memory1 GB
NetworkingPublic subnet and public IPv4 address
SSH accessAdd your SSH public key

In the Console, open Compute → Instances → Create instance, choose the image, then select Change shape → AMD → VM.Standard.E2.1.Micro. Leave default VCN/subnet creation enabled unless you already have a suitable public subnet. Click Create and wait for the instance to show Running.

Important: This tiny VM is appropriate for HAProxy and Tailscale only. Do not run Minecraft on it. Oracle documents the shape as 1 GB RAM, 1/8 OCPU, and up to 50 Mbps internet bandwidth. Check Oracle's Always Free resource page before creating it, since eligibility and availability can change.

Connect over SSH

ssh ubuntu@YOUR_ORACLE_PUBLIC_IP

Use the username shown for the image you selected. Ubuntu images normally use ubuntu.

4. Install Tailscale on the Oracle VM

curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up
tailscale status

Authorize the VM into the same Tailscale network as the computer running Minecraft. On the Minecraft PC, get its Tailscale IPv4 address:

tailscale ip -4

From the Oracle VM, test that address before configuring HAProxy:

sudo apt update
sudo apt install netcat-openbsd -y
nc -vz MINECRAFT_PC_TAILSCALE_IP 25565

A successful test ends with succeeded!. If it fails, check Tailscale, Windows Firewall, and that Minecraft is running before continuing.

5. Configure Minecraft

Open the server's server.properties and leave the bind address blank:

server-ip=
server-port=25565

Restart the Minecraft server. Make sure Windows Firewall permits TCP 25565 from the Tailscale interface or network.

6. Install and configure HAProxy

sudo apt update
sudo apt install haproxy -y
sudo cp /etc/haproxy/haproxy.cfg /etc/haproxy/haproxy.cfg.backup
sudo nano /etc/haproxy/haproxy.cfg

Replace the configuration with this, substituting the Minecraft PC's Tailscale IP:

global
    log /dev/log local0
    log /dev/log local1 notice
    daemon

defaults
    log global
    mode tcp
    option tcplog
    timeout connect 10s
    timeout client 1h
    timeout server 1h

frontend minecraft
    bind *:25565
    default_backend minecraft_home

backend minecraft_home
    server home MINECRAFT_PC_TAILSCALE_IP:25565 check
sudo haproxy -c -f /etc/haproxy/haproxy.cfg
sudo systemctl restart haproxy
sudo systemctl enable haproxy
sudo ss -lntp | grep 25565

The validation should say the configuration is valid, and the final command should show HAProxy listening on port 25565.

7. Allow Minecraft through Oracle and Ubuntu

Oracle VCN security list

Open Networking → Virtual cloud networks, choose the VCN and public subnet used by the instance, then edit its security list ingress rules. Add:

Source CIDRProtocolDestination portPurpose
0.0.0.0/0TCP25565Minecraft Java relay
Your public IP/32TCP22SSH management

If you cannot restrict SSH to your address, use 0.0.0.0/0 temporarily and secure the account with SSH keys. Do not expose any port for Tailscale.

Ubuntu firewall

sudo ufw status
sudo ufw allow 22/tcp
sudo ufw allow 25565/tcp

8. Test the public relay

Copy the instance's public IPv4 address from the Oracle Console. In Minecraft Java, connect to:

YOUR_ORACLE_PUBLIC_IP:25565

On the VM, these commands help while testing:

sudo journalctl -u haproxy -f
sudo tcpdump -ni any tcp port 25565

9. Add a Minecraft domain

Create a DNS-only A record at your DNS provider:

TypeNameValue
AmcYOUR_ORACLE_PUBLIC_IP

Players can then use mc.example.com. Do not use an HTTP reverse proxy for this record; Minecraft needs a direct TCP connection to HAProxy.

10. Remove the home port forward

Once the public test works, remove any router rule that exposes TCP 25565 to the home Minecraft PC. Only the Oracle VM should be reachable from the internet.

  • Keep the Oracle security list limited to SSH and TCP 25565.
  • Restrict SSH to your own IP where possible.
  • Use Tailscale ACLs to limit what the relay can reach.
  • Keep Ubuntu, Tailscale, and HAProxy updated.
  • Watch HAProxy logs for unexpected or abusive traffic.
Always Free is not an uptime guarantee: Oracle can reclaim idle Always Free instances under its policy, and free-shape capacity may be unavailable. Keep your HAProxy configuration backed up and be prepared to recreate the relay if needed.

11. Troubleshooting

HAProxy shows the backend as DOWN

nc -vz MINECRAFT_PC_TAILSCALE_IP 25565
tailscale status

Fix the private Tailscale path, Windows Firewall, or Minecraft server first.

No one can reach Oracle on port 25565

Confirm HAProxy is listening, then check both the Oracle VCN security-list rule and UFW. Both layers must allow TCP 25565.

The Always Free shape has no capacity

Try another availability domain if your home region offers one, or try again later. Oracle's capacity for free shapes is not guaranteed.
